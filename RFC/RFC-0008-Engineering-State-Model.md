# RFC-0008

## Title

Engineering State Model

## Status

Draft

---

## Motivation

Engineering projects are often described only by their source code.

ARTEM proposes that a project is defined by its complete Engineering State.

Source code is only one component.

---

## Proposed Engineering State

Engineering State

├── Knowledge State
├── Requirements State
├── Architecture State
├── Decision State
├── Source Code State
├── Test State
├── Documentation State
├── Configuration State
├── Environment State
└── Quality State

---

## Principle

Every Engineering Transition changes one or more components of the Engineering State.

---

## Objective

Engineering aims to produce reproducible transitions between complete Engineering States.
